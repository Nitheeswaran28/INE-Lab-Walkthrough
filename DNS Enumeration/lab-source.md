# DNS Enumeration source notes

INE/AttackDefense walkthrough 2019 reports the lab's resolver checks, DNSEnum and DNSRecon results, an unrestricted transfer, and comparisons with the Metasploit report. The manual spells DNSRecon inconsistently in one export example. This summary preserves the findings and local inspection commands. It omits active zone transfer, bulk discovery, and wordlist enumeration procedures.
